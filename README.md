# Industrial Equipment Failure Prediction

## About the Project

This is one of the Machine Learning projects I worked on while learning Data Science.

The main aim of this project was to predict whether industrial equipment would fail based on different equipment-related features.

I started by exploring the dataset, understanding the features, and preparing the data for Machine Learning. After that, I trained a Decision Tree Classifier to predict equipment failure.

I also worked on connecting the trained model with a web application.

## What I Worked On

- Explored the industrial equipment failure dataset.
- Performed data analysis and understood the features.
- Prepared the data for Machine Learning.
- Split the data into training and testing sets.
- Built a Decision Tree Classification model.
- Evaluated the model using Accuracy, Precision, Recall and F1 Score.
- Saved the trained model using Joblib.
- Created a web application for predictions.

## Model Performance

The Decision Tree Classifier achieved the following results during evaluation:

| Metric | Score |
|---|---:|
| Accuracy | 99.85% |
| Precision | 100% |
| Recall | 95.24% |
| F1 Score | 97.56% |

These results are from my project evaluation.
